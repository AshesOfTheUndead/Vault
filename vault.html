      What this is

      A tiny private vault for secrets you don't want in chat logs: API keys, passwords, tokens.

      It also stores environment variables, Render style. Mark sensitive ones as secret to mask them in lists.

      Where things live

      Secrets live in ~/Vault/Secrets/. Env vars live in ~/Vault/EnvVars/.

      Each entry gets its own folder with value.txt and metadata. Nothing is encrypted by design.

      How to use

      Switch tabs between Secrets and Env Vars. / focuses the filter. The eye reveals a value, the copy icon copies it, the trash icon opens a confirmation dialog to delete. Press ? for full shortcuts.
